# DevOps - Session 04 - Bài 1

Khởi tạo Local Repository và cấu hình danh tính tác giả ở cấp local bằng Git.

Bài làm thực hành các thao tác: `git init`, `git config --local` (tên và email), tạo tệp, `git add`, `git commit` đầu tiên, và đọc trạng thái bằng `git status`, lịch sử bằng `git log`. Toàn bộ output trong báo cáo là kết quả chạy thật.

Báo cáo chi tiết: [homework/session_04/ex1/README.md](homework/session_04/ex1/README.md)

## Danh sách file

| Đường dẫn | Mô tả |
